# 线上协作规范 — 鉴泉识珍

---

## 一、代码协作（GitHub）

### 仓库

```
github.com/Zheng-314/Coin
```

### 分支策略

```
master          ← 稳定版本，只通过 PR 合并，不直接 push
  ├── dev        ← 开发主分支，各组代码在此汇总
  │   ├── dev/system-xxx     ← 系统组开发分支
  │   ├── dev/data-xxx       ← 数据组开发分支
  │   └── dev/model-xxx      ← 模型组开发分支
  └── release/*  ← 答辩/展示用的发布分支
```

### 工作流程

```bash
# 1. 每个人从 dev 拉自己的分支
git checkout dev
git pull origin dev
git checkout -b dev/system-fix-docker

# 2. 开发和提交
git add -A
git commit -m "fix: Docker启动脚本修bug"

# 3. 推送到 GitHub
git push origin dev/system-fix-docker

# 4. 在 GitHub 上创建 Pull Request → 合入 dev
# 5. 组长 Review 通过后合并
```

### 提交规范

```
feat: 新功能      feat: 添加品相评级API
fix: 修bug        fix: 修复YOLO检测跳过率过高
docs: 文档        docs: 更新数据集说明
refactor: 重构    refactor: 抽取共享推理模块
test: 测试        test: 补充auth模块测试
```

### 禁止事项

- **禁止直接 push master**
- **禁止提交大文件**（图片、模型、venv）——已在 `.gitignore` 配置
- **禁止提交 .env**（含 API Key）

## 二、沟通协作

### 工具

| 用途 | 工具 |
|------|------|
| 代码 | GitHub + Pull Request |
| 任务跟踪 | GitHub Issues / Projects |

```
时间: 每周一/周四 21:00，15分钟
内容: 每人30秒说三件事
  1. 上周做了什么
  2. 这周要做什么
  3. 遇到什么阻塞
```

### 大文件分享

14GB 图片不通过 Git 传。用网盘共享链接：

```

文件结构:

  ├── raw.zip          (原始图，约 7GB)
  ├── models.zip       (模型文件，约 200MB)
  └── processed.zip    (裁剪图，约 3.5GB)
```

## 三、环境统一

所有人用相同的开发环境：

### 系统组

```bash
# 后端
Python 3.11
pip install -r requirements.txt
pip install langchain-graphrag

# 前端
Node.js 20+
cd frontend && npm install

# 数据库
Neo4j 5.x 社区版
```

### 数据组

```bash
Python 3.11
pip install requests beautifulsoup4 pandas pillow opencv-python
```

### 模型组

```bash
Python 3.11
# PyTorch + CUDA（本地开发）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install ultralytics onnxruntime scikit-learn matplotlib

# 华为昇腾（训练时）
# 见 docs/硬件方案.md
```
