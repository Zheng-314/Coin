# 第一部分：项目功能介绍

## 项目定位

**一句话**：古钱币版的"拍照识花"+"ChatGPT"——用户上传古钱币正反面照片，系统通过深度学习模型识别这是什么币、品相如何、值多少钱，并基于知识图谱回答历史背景和市场行情。

**应用场景**：省级大创比赛 + 商业化双轨。面向钱币收藏市场（600亿+），服务新人藏家、币商、拍卖行的 AI 鉴定需求。

## 功能二：智能鉴定（拍照识币）

### 功能描述

**核心功能。** 用户上传古钱币正反面两张照片，系统自动检测钱币位置、裁剪、推理，返回 Top-3 版式识别结果及置信度。

### 功能点

| 功能点 | 说明 | 状态 |
|--------|------|------|
| 双图上传 | 正面+反面两张图同时上传 | ✅ |
| YOLO 目标检测 | 自动定位图片中的钱币位置并裁剪 | ✅ |
| ONNX 细粒度分类 | 92 类机制银币版式识别，输出 Top-3 | ✅ |
| 4候选推理 | processed/raw × normal/swapped 四种组合取最优 | ✅ |
| 置信度展示 | Top-3 结果含置信度百分比 | ✅ |
| 图片预览 | 上传前预览正反面图片 | ✅ |

### 技术实现

| 技术点 | 具体方案 | 对应文件 |
|--------|----------|----------|
| 目标检测 | YOLOv8 (`best1.pt` / `best2.pt`) 检测钱币区域 | [services/yolo_service.py](backend/services/yolo_service.py) |
| 细粒度分类 | ONNX Runtime 推理 `best_model.onnx`（92类输出） | [services/onnx_service.py](backend/services/onnx_service.py) |
| 共享推理逻辑 | 4候选策略：原图/处理后 × 正常/交换顺序 | [services/inference_service.py](backend/services/inference_service.py) |
| 模型加载 | 应用启动时预加载，避免首次请求等待 | [models/model_loader.py](backend/models/model_loader.py) |
| 92类标签 | JSON 分类体系映射 | [instance/classification.json](backend/instance/classification.json) |
| 分类体系 | 8大类92叶子类，覆盖古钱/机制银币/机制铜币/纸币/金币/纪念币/花钱/外国钱币 | [instance/classification_full.json](backend/instance/classification_full.json) |
| 前端上传 | Element Plus Upload 组件 + 图片预览 | [views/PredictView.vue](frontend/src/views/PredictView.vue) |
| 图片预处理 | OpenCV + Pillow 图像处理 | [services/inference_service.py](backend/services/inference_service.py) |

### 推理流程

```
用户上传正反面图
      │
      ▼
YOLO (best1.pt) 检测钱币位置 → 裁剪
      │
      ▼
4候选推理（processed/raw × normal/swapped）
      │
      ▼
ONNX (best_model.onnx) 双图输入 → 92维概率向量
      │
      ▼
取最高概率候选 → Top-3 结果 [{name, confidence}, ...]
```

## 功能三：智能问答（GraphRAG + LLM）

### 功能描述

用户用自然语言提问古钱币相关问题，系统支持三种搜索模式，结合知识图谱和 LLM 生成准确回答。支持流式输出（SSE）。

### 功能点

| 功能点 | 说明 | 状态 |
|--------|------|------|
| 本地搜索 (Local) | GraphRAG Local Search：ChromaDB 向量检索 + LLM 合成 | ⚠️ 依赖未完整安装 |
| 全局搜索 (Global) | GraphRAG Global Search：社区摘要聚合 + LLM 合成 | ⚠️ 依赖未完整安装 |
| 联网搜索 (Web) | Tavily API 联网搜索 + LLM 总结 | ✅ |
| 图片问答 | 上传图片+提问 → Qwen-VL 视觉分析 → 结果拼入问题 → 搜索 | ✅ |
| 流式输出 | SSE (Server-Sent Events)，逐字推送到前端 | ✅ |
| 降级链 | GraphRAG 不可用 → SQLite LIKE 关键词检索 → LLM 直接回答 | ✅ |
| 上下文对话 | 多轮对话支持 | ✅ |

### 技术实现

| 技术点 | 具体方案 | 对应文件 |
|--------|----------|----------|
| GraphRAG 引擎 | Microsoft GraphRAG (LangChain 集成) | [services/__init__.py](backend/services/__init__.py) |
| 向量存储 | ChromaDB (Embedding: text-embedding-3-small via 硅基流动) | [services/rag_service.py](backend/services/rag_service.py) |
| LLM 合成 | DeepSeek API / OpenAI API（通过环境变量配置） | [services/rag_service.py](backend/services/rag_service.py) |
| 联网搜索 | Tavily Search API | [services/rag_service.py](backend/services/rag_service.py) |
| 视觉分析 | 阿里 Qwen-VL 多模态模型（图片问答优先） | [routes/qa.py](backend/routes/qa.py) |
| 降级检索 | SQLite LIKE 关键词匹配兜底 | [routes/qa.py](backend/routes/qa.py) |
| 流式输出 | Flask SSE (text/event-stream) | [routes/qa.py](backend/routes/qa.py) |
| 前端流式处理 | `useChatStream.js` composable | [composables/useChatStream.js](frontend/src/composables/useChatStream.js) |
| 前端聊天界面 | 聊天气泡 + Markdown 渲染 | [components/QA.vue](frontend/src/components/QA.vue) |

### 搜索模式对比

| 模式 | 数据源 | 适用场景 | 速度 |
|------|--------|----------|------|
| 本地 Local | ChromaDB 向量 + GraphRAG 实体/关系 | 事实型问题（"袁大头哪年铸造的"） | 快 |
| 全局 Global | GraphRAG 社区摘要 | 概括型问题（"机制银币有哪些省份造"） | 中 |
| 联网 Web | Tavily 实时搜索 | 市场行情、最新资讯 | 慢 |
