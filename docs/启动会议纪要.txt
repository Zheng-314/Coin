鉴泉识珍 — 项目启动会议
2026-07-16  项目负责人：阿轩

============================================================
一、项目是什么
============================================================

AI 古钱币智能鉴定系统。用户上传正反面照片，系统完成 5 件事：

  1. 版式识别 — 这是什么币（92 种机制银币）
  2. 品相评级 — 保存状态（XF/VF/AU/MS 四档）
  3. 分数评级 — 具体分数（01-66 分）
  4. 智能问答 — 历史背景、市场行情
  5. 以图搜图 — 数据库里找最像的币

技术栈：Vue 3 + Flask + YOLO/ONNX/VGG19 + GraphRAG + 华为昇腾


============================================================
二、项目现状
============================================================

智能鉴定    — 能用，但只覆盖 31/92 类，模型是学长的 ONNX
品相/分数   — 训练数据不够，代码有但没跑
智能问答    — GraphRAG 没装，靠远程 API 硬撑
知识图谱    — Neo4j 没启动，前端被迫降级
估值报告    — 纯文字拼凑，无量化模型
真伪鉴别    — 完全没有
Docker      — 配置写了，没完整测试
数据集      — 7559 枚原始图，6077 对已裁好标注好
测试        — 有 CI，覆盖率不到 1%

一句话：骨架搭好了，数据和模型需要补。


============================================================
三、目标展望
============================================================

【功能目标】
  现在                          三个月后
  拍照识别 31 类                拍照识别 92 类全覆盖
  没有品相/分数                 自动评级品相 + 分数
  问答靠 API 勉强回答           知识图谱驱动问答
  估值是纯文字                  基于拍卖数据的量化估值
  只跑 Windows                  Windows + 华为昇腾双版本

【模型目标】
  YOLO 检测    检测率 70% → 95%+
  版式识别     31 类 → 92 类全覆盖，Top-1 > 90%
  品相评级     从零开始，准确率 > 85%
  分数评级     从零开始，准确率 > 80%
  以图搜图     512 维特征向量检索，找出最相似的 10 枚

【数据目标】
  标注图片      6,077 对 → 10,000+ 对
  类别覆盖      31/92 → 92/92 全部
  品相标签      无 → 完整率 95%+
  知识库        500 条 → 5,000+ 条
  公开数据集    无 → HuggingFace / Zenodo 发布

【产出目标】
  数据集论文    1 篇
  方法论文      1 篇
  软件著作权    1 项
  冲击国家级大创
