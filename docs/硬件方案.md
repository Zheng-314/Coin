## 三、模型迁移路径

### PyTorch → 昇腾 PyTorch

昇腾原生支持 PyTorch，不需要大改代码：

```python
# 原来（NVIDIA GPU）
model = VGG19(num_classes=92).cuda()

# 改为（昇腾 NPU）
import torch_npu
model = VGG19(num_classes=92).npu()
```

`torch_npu` 是华为提供的 PyTorch 昇腾适配插件，API 近乎相同。

### 训练脚本变更

```diff
# train.py 的改动
- device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
+ import torch_npu
+ device = torch.device("npu" if torch_npu.is_available() else "cpu")

- model = VGG19(num_classes=92).to(device)   # 无需改动
- input1 = input1.to(device)                  # 无需改动
- loss.backward()                             # 无需改动
```

### ONNX 推理

昇腾支持 ONNX Runtime，`best_model.onnx` 可以直接在 Ascend 310 上跑。已有 `inference_worker.py` 是 Ak 腾 `acl` API 写的，可以继续用。

## 五、关键命令

### 环境安装

```bash
# CANN 工具包
wget https://ascend-repo.obs.cn-east-2.myhuaweicloud.com/...
./Ascend-cann-toolkit_8.0.0_linux-x86_64.run --install

# PyTorch + 昇腾适配
pip install torch==2.1.0
pip install torch-npu

# 验证
python -c "import torch_npu; print(torch_npu.npu.is_available())"
```

### 模型转换（ONNX → OM）

```bash
# ONNX 转 Ascend OM 格式（已有 .onnx 可直接转）
atc --model=best_model.onnx \
    --framework=5 \
    --output=best_model \
    --soc_version=Ascend310P3 \
    --input_shape="input1:1,3,224,224;input2:1,3,224,224"
```

### 训练启动

```bash
python training/train.py \
    --device npu \
    --batch_size 64 \
    --epochs 80 \
    --data_dir data/processed/splits/
```
