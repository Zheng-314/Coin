# 项目通读指南 — 鉴泉识珍

> 项目负责人必读 | 2026-07-16

---

## 一、这个项目是什么

一个 Web 应用，用户上传古钱币正反面照片，系统告诉用户这是什么币、品相如何、值多少钱。底层用深度学习模型做图像识别，用知识图谱做问答。

**一句话：钱币版的"拍照识花"+"ChatGPT"。**

---

## 二、跑起来（5分钟）

```bash
# 终端1: 后端
cd backend
python app_new.py          # 启动在 :5001，会自动加载模型（30秒）

# 终端2: 前端
cd frontend
npm run dev                 # 启动在 :5173

# 浏览器打开 http://localhost:5173
```

## 三、系统架构（一张图）

```
浏览器 (Vue 3)
    │
    │ HTTP / SSE
    ▼
Flask 后端 (:5001)
    │
    ├── /predict         → YOLO 检测 + ONNX 分类 → 版式识别结果
    ├── /api/ask         → GraphRAG 检索 + LLM  → 问答回复
    ├── /api/valuation   → 搜索 + LLM           → 估值报告
    ├── /api/artifacts/* → SQLite 查询          → 钱币数据库
    ├── /api/users/*     → JWT 认证             → 登录/注册
    └── /api/report/*    → PDF 生成             → 鉴定报告

模型层（本地）
    ├── YOLO (best1.pt / best2.pt)      钱币检测
    ├── ONNX (best_model.onnx)          92类版式分类
    └── VGG19 (training/model.py)       品相/分数分类

外部 API（远程）
    ├── DeepSeek    → 问答生成
    ├── 硅基流动     → Embedding 向量化
    ├── 阿里 Qwen-VL → 图片视觉分析
    └── Tavily      → 联网搜索

数据层
    ├── SQLite (user.db / item.db)     用户/知识库
    ├── Neo4j (可选)                    知识图谱
    ├── ChromaDB                        向量存储
    └── Parquet/Pickle                  GraphRAG 构件
```

## 四、功能逐个走通

### 功能 1：用户登录注册

```
前端: LoginView.vue / RegisterView.vue
后端: routes/auth.py

流程:
  注册: POST /api/users/register {username, password}
        → user.db 写入用户 → 返回 201
  
  登录: POST /api/users/login {username, password}
        → 验证密码(bcrypt) → 生成 JWT token (24h有效)
        → 前端存 localStorage → 所有请求带 Authorization header

关键文件:
  - routes/auth.py      : 注册/登录接口
  - utils/decorators.py : @token_required 装饰器
  - stores/auth.js      : 前端 Pinia 状态管理
```

### 功能 2：智能鉴定（拍图识币）

```
前端: PredictView.vue
后端: routes/predict.py

流程:
  1. 用户上传两张图（正反面）
  2. POST /predict {image1, image2}
  3. 后端:
     a. YOLO (best1.pt) 检测钱币位置 → 裁剪
     b. 4候选推理: processed/raw × normal/swapped
        （处理过的图和原图 × 正常顺序和交换顺序）
     c. ONNX (best_model.onnx) 双图输入 → 92维概率
     d. 取概率最高的那个候选 → Top-3 结果
  4. 返回: [{name: "四川军政府壹圆普通", confidence: 0.92}, ...]

关键文件:
  - routes/predict.py          : 主接口
  - services/yolo_service.py   : YOLO 检测
  - services/onnx_service.py   : ONNX 推理
  - services/inference_service.py : 共享推理逻辑
  - models/model_loader.py     : 模型加载
  - views/PredictView.vue      : 前端上传页
```

### 功能 3：智能问答

```
前端: KnowledgeEntry.vue → QA.vue
后端: routes/qa.py

三种搜索模式:
  local  → GraphRAG Local Search (ChromaDB 向量 + LLM 合成)
  global → GraphRAG Global Search (社区摘要 + LLM 聚合)
  web    → Tavily 联网搜索 + LLM 总结

降级链:
  GraphRAG 不可用 → SQLite LIKE 关键词检索 → LLM 直接回答

图片问答:
  上传图 + 问题 → Qwen-VL 视觉分析 (优先) → YOLO+ONNX (降级)
    → 分析结果拼到问题前面 → 发给搜索 → LLM 合成

流式响应: SSE (Server-Sent Events)，一个字一个字推到前端

关键文件:
  - routes/qa.py              : 问问接口
  - services/rag_service.py   : 搜索+LLM 合成
  - services/__init__.py      : GraphRAG 初始化
  - components/QA.vue         : 前端聊天界面
  - composables/useChatStream.js : SSE 流式处理
```

### 功能 4：钱币数据库

```
前端: HomeView.vue
后端: routes/artifacts.py

功能:
  - 搜索: GET /api/artifacts/searchItems?keyword=...&page=1&limit=20
  - 筛选: dynasty (朝代), province (省份), grade (品相), year range
  - 详情: GET /api/artifacts/search?id={pid}
  - 分类: GET /api/artifacts/classification → classification.json

数据源: backend/instance/item.db (SQLite, 500条)
图片: Cloudinary CDN 上的图片 URL

关键文件:
  - routes/artifacts.py     : 路由
  - utils/helpers.py        : 数据解析
  - views/HomeView.vue      : 前端搜索页面
  - components/ArtifactCard.vue : 卡片组件
```

### 功能 5：估值报告

```
前端: ValuationView.vue
后端: routes/valuation.py

流程:
  1. 用户输入币名 + 品相
  2. POST /api/valuation {coinName, coinGrade}
  3. 后端并行:
     a. GraphRAG Global Search → 历史背景
     b. Tavily 联网搜索 → 市场行情
  4. 合并 → Markdown 报告 → 前端渲染

关键文件:
  - routes/valuation.py     : 估值接口
  - views/ValuationView.vue : 前端页面
```

### 功能 6：PDF 报告导出

```
前端: PredictView.vue (导出按钮)
后端: routes/report.py

流程:
  1. POST /api/report/identify {coinName, confidence, top3}
  2. 后端用 fpdf2 生成 PDF
  3. 返回 PDF 文件下载

关键文件:
  - routes/report.py : PDF 生成 + 批量鉴定 + 价格历史
```

### 功能 7：知识图谱可视化

```
前端: KnowledgeEntry.vue → KG.vue
后端: routes/artifacts.py → get_kg_graph()

流程:
  1. GET /api/kg/graph?limit=320
  2. Neo4j 查询 (优先) → SQLite 兜底
  3. 返回 {nodes: [...], edges: [...]}
  4. vis-network 渲染交互式图谱

关键文件:
  - routes/artifacts.py : get_kg_graph()
  - components/KG.vue   : 前端图谱可视化
```

### 功能 8：工具箱

```
前端: ToolsView.vue
后端: routes/report.py (批量鉴定) + price_history 接口

两个 Tab:
  批量鉴定: 上传多组图片 → POST /api/predict/batch → CSV 导出
  价格追踪: 手动记录价格 → CRUD /api/price-history
```

## 九、你汇报时怎么说

```
"我们这个项目叫鉴泉识珍，是一个融合计算机视觉和知识图谱的古钱币智能鉴定系统。

用户上传正反面照片，系统完成三件事：
第一，版式识别——92类机制银币分类，告诉用户这是什么币；
第二，品相评级——评估钱币的保存状态和分数；
第三，智能问答——基于知识图谱回答历史背景和市场行情。

技术创新上，我们正在做两个方向：
一是多任务联合学习，一个模型同时完成版式识别和品相评级；
二是知识图谱增强分类，用币种间的关系信息提升识别精度。

目前数据集有7500多枚标注钱币，系统已经能演示完整流程。
下一步重点是补充数据覆盖全部92类、训练自己的模型、以及增加真伪鉴别功能。"
```
