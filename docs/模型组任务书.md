# 模型组任务书

> 成员 2 人 | 负责人：待指定

---

## 职责

训出能用的模型，做出学术创新。版式识别 + 品相评级 + 真伪鉴别 + 多任务学习 + 方法论文。

---

## 子任务

### 任务一：版式识别 baseline

**目标**：用现有数据训出分类模型，建立评测基线。

| # | 内容 | 工作量 |
|------|------|------|
| 1.1 | 用 `data/processed/splits/` 训练 VGG19（31类，6077对） | 2天 |
| 1.2 | Top-1 / Top-3 精度评测 | 0.5天 |
| 1.3 | 混淆矩阵 + 每类精度分析 | 0.5天 |
| 1.4 | 与 ONNX 模型（学长训的）对比评测 | 1天 |
| 1.5 | 模型卡片文档 | 0.5天 |

**交付物**：`.pth` 模型 + 评测报告。

---

### 任务二：多任务联合学习（核心创新点）

**目标**：一个 backbone 同时输出版式+品相+分数。这是论文的卖点。

| # | 内容 | 工作量 |
|------|------|------|
| 2.1 | 多任务学习论文调研（MTL / MMoE / PLE） | 2天 |
| 2.2 | 设计多任务架构（共享 VGG19 + 三个 head） | 1天 |
| 2.3 | 实现多任务损失函数 | 2天 |
| 2.4 | 训练 + 评测（对比单任务 baseline） | 3天 |
| 2.5 | 消融实验数据汇总 | 1天 |

**架构**：

```
正面 ──┐
       ├── VGG19 Backbone ──┬── Head1: 版式 92类
反面 ──┘                    ├── Head2: 品相 4类
                             └── Head3: 分数 回归
```

**交付物**：多任务模型 + 消融实验表格。

---

### 任务三：知识图谱增强分类（第二创新点）

**目标**：用币种间关系信息提升小类别精度。

| # | 内容 | 工作量 |
|------|------|------|
| 3.1 | 从 entities/relationships 构建币种关系图 | 2天 |
| 3.2 | 设计知识增强模块（GCN / Cross-Attention） | 2天 |
| 3.3 | 训练 + 评测 | 3天 |
| 3.4 | 消融实验（纯视觉 vs 知识增强） | 1天 |

**交付物**：知识增强模型 + 对比数据。

---

### 任务四：真伪鉴别

**目标**：建立真假二分类 baseline。

| # | 内容 | 工作量 |
|------|------|------|
| 4.1 | 文献调研 | 1天 |
| 4.2 | 构建真假数据集（数据组协助 + 数据增强） | 3天 |
| 4.3 | 训练真假分类模型 | 2天 |
| 4.4 | 评测（准确率、假阳性率） | 1天 |

**交付物**：真伪鉴别模型 + 报告。

---

### 任务五：方法论文

**目标**：产出可投稿的学术论文。

| # | 内容 | 时间 |
|------|------|------|
| 5.1 | 引言 + 相关工作 | 第3周 |
| 5.2 | 方法描述（多任务架构 + 知识增强） | 第4周 |
| 5.3 | 实验（数据集、baseline、消融） | 第5-6周 |
| 5.4 | 结论 + 排版 + 投稿 | 第7-8周 |

**论文卖点模板**：

> 本文提出一种知识增强的多任务古钱币细粒度识别方法。在 VGG19 双路输入基础上：(1) 通过多任务联合学习同时完成版式识别、品相评级和分数评估；(2) 引入知识图谱特征增强模块，利用币种间的铸造关系、朝代联系等先验知识提升分类精度。在自建的 10,000+ 枚中国机制银币数据集上，多任务模型 Top-1 分类准确率达 XX%，知识增强带来 X% 的小类别精度提升。
