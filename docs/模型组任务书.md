# 模型组任务书

> 成员 3 人 | 负责人：待指定

---

## 职责

训出能用的模型，做出学术创新。负责版式识别、品相评级、真伪鉴别、多任务学习、论文。

---

## 子任务

### 任务一：版式识别 baseline

**目标**：用现有数据训出版式识别模型，作为后续改进的对比基线。

| 序号 | 内容 | 工作量 |
|------|------|------|
| 1.1 | 用 `data/processed/splits/` 训练 VGG19 双路分类（31类，6077对） | 2天 |
| 1.2 | Top-1 / Top-3 准确率评测，每类精度统计 | 1天 |
| 1.3 | 混淆矩阵生成和分析 | 0.5天 |
| 1.4 | 与现有 ONNX 模型（学长训的）做对比评测 | 1天 |
| 1.5 | 模型文档（模型卡片：输入/输出/精度/局限） | 0.5天 |

**评测指标**：

```
总体: Top-1 Acc, Top-3 Acc, Macro F1
每类: Precision, Recall, F1
性能: 推理延迟 P50/P95 (ms), 模型大小 (MB)
```

**交付物**：训练好的 `.pth` 文件 + 评测报告 + 模型卡片。

---

### 任务二：多任务联合学习

**目标**：一个 backbone 同时输出版式+品相+分数，学术创新点。

| 序号 | 内容 | 工作量 |
|------|------|------|
| 2.1 | 调研多任务学习论文（MTL、MMoE、PLE 等） | 2天 |
| 2.2 | 设计多任务架构（共享 backbone + 三个 task head） | 2天 |
| 2.3 | 实现多任务损失函数（版式 CrossEntropy + 品相 CrossEntropy + 分数回归） | 2天 |
| 2.4 | 多任务训练 + 评测（对比单任务 baseline） | 3天 |
| 2.5 | 输出对比表格（单任务 vs 多任务的每类精度） | 1天 |

**架构示意**：

```
正面图 ──┐
         ├── VGG19 Backbone ──┬── Head1: 版式分类 (92类)
反面图 ──┘                    ├── Head2: 品相分类 (4类)
                               └── Head3: 分数回归 (0-70)
```

**交付物**：多任务模型 + 消融实验数据。

---

### 任务三：知识图谱增强分类

**目标**：用知识图谱的币种关系信息提升分类精度，学术创新点。

| 序号 | 内容 | 工作量 |
|------|------|------|
| 3.1 | 从 GraphRAG entities/relationships 构建币种关系图（同朝代、同省份、同币种） | 2天 |
| 3.2 | 设计知识增强模块（GCN 或 Cross-Attention 注入图谱信息） | 3天 |
| 3.3 | 训练 + 评测（对比纯视觉 baseline） | 3天 |
| 3.4 | 消融实验（有无知识增强的精度对比） | 2天 |

**交付物**：知识增强模型 + 消融实验数据。
