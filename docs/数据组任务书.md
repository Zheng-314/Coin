## 子任务

### 任务一：数据爬取

**目标**：92 类每类至少 100 对正反面图。

| 序号 | 内容 | 工作量 |
|------|------|------|
| 1.1 | PCGS 爬虫开发（输入：搜索条件，输出：图片+元数据） | 3天 |
| 1.2 | 防反爬处理（IP 代理池、请求频率控制、User-Agent 轮换） | 1天 |
| 1.3 | 爬虫运维（持续运行，每天爬取约 500 对） | 持续 |
| 1.4 | 多数据源补充（NGC、华夏古泉、钱币天堂） | 2天 |

**爬虫规格**：

```
输入：PCGS 搜索页 URL 或搜索条件
输出：
  ├── 正面图: {证书编号}_front.jpg
  ├── 反面图: {证书编号}_back.jpg
  └── 元数据追加到 data/metadata.csv:
       证书编号, 币名, 品相, 分数, 年份
```

**交付物**：爬虫代码 + 运行日志 + 每日增量统计。

---

### 任务二：数据清洗

**目标**：metadata.csv 准确率 >95%。

| 序号 | 内容 | 工作量 |
|------|------|------|
| 2.1 | 修正币名→92类映射错误（如"西藏银币十两"错标"湖北双龙"） | 2天 |
| 2.2 | 品相/分数字段补全（metadata.csv 空缺项） | 1天 |
| 2.3 | 图片质量检查（模糊、遮挡、非钱币图筛选删除） | 2天 |
| 2.4 | coindata 中 1,476 对 YOLO 未检测到的图片人工检查 | 1天 |
| 2.5 | 数据去重（同一证书号不要存两份） | 0.5天 |

**清洗规范**：

```
1. 币名映射：人工核对，存疑标为"待确认"
2. 品相标注：PCGS 数据直接采信，其他来源标"人工评估"
3. 图片质量：分辨率<200px 的丢弃，纯文字/截图丢弃
```

**交付物**：清洗后的 metadata.csv + 数据质量报告。

### 任务三：数据集构建

**目标**：国内首个公开的中国机制银币多任务标注数据集。

| 序号 | 内容 | 工作量 |
|------|------|------|
| 3.1 | YOLO 裁剪全量图 → `data/processed/crops/` | 已部分完成，增量运行 |
| 3.2 | 92 类标签映射 → 每类统计样本数 | 1天 |

| 3.4 | 数据集卡片文档（参考 Datasheets for Datasets 模板） | 1天 |

**数据集最终样子**：

```
coin-dataset/
├── images/             全部裁剪图 (.jpg)
├── labels.csv          版式识别标签

├── metadata.csv        元数据
```

**交付物**：可发布的数据集 + HuggingFace Dataset Card。
