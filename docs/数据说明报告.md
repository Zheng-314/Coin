## 二、数据到功能的全流程

### 功能一：智能鉴定（版式识别）

```
用户上传正反面图片
        │
        ▼
   YOLO 检测（best1.pt）
   找到图片里的钱币位置
        │
        ▼
   ONNX 分类（best_model.onnx）
   输入：两张裁剪后的图
   输出：92维概率向量
        │
        ▼
   classification.json 映射
   概率最大 → 类别名称
        │
        ▼
   返回给用户：
   "四川军政府壹圆普通，置信度 92%"
```

### 功能二：品相评级

```
用户上传图片 + 已知币种
        │
        ▼
   YOLO 检测裁剪
        │
        ▼
   VGG19 分类（训练代码在 training/train.py）
   输入：两张图
   输出：XF / VF / AU / MS 四类之一
```

### 功能三：分数评级

```
用户上传图片 + 已知币种
        │
        ▼
   YOLO 检测裁剪
        │
        ▼
   VGG19 分类
   输入：两张图
   输出：01-66 分
```

### 功能四：智能问答

```
用户提问 "袁大头值多少钱"
        │
        ├── GraphRAG 检索（本地）
        │   从 entities.parquet + chroma.sqlite3 找相关实体
        │
        ├── SQLite 关键词兜底
        │   从 item.db (500条) 模糊匹配
        │
        └── 组装上下文 → DeepSeek API 生成回答
```

### 3.1 原始图片

| 属性 | 值 |
|------|------|
| 位置 | `data/images/` |
| 数量 | 11,033 张 |
| 大小 | 14 GB |
| 格式 | JPG |

## 五、当前数据缺口

| 缺失项 | 影响 | 方案 |
|------|------|------|
| 品相/分数分类训练图片（~66,000 张） | 无法重新训练品相/分数模型 | 找合作同学索要或重新爬取 |
| YOLO 检测训练数据 | 无法重新训练或优化检测模型 | 需要标注 bounding box |
| 92 类中仅覆盖 31 类 | 版式识别模型覆盖不全 | 继续爬 PCGS 扩充到全 92 类 |
| `data/images/` 与 `coins.csv` 配对率仅 19.8% | 大量元数据无对应图片 | 补充爬取 |
| 无真假鉴别数据 | 鉴定系统核心功能缺失 | 需单独构建真伪数据集 |
