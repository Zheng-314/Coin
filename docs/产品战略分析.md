## 一、为什么这个项目有戏

### 市场规模

- 中国钱币收藏市场 600 亿+，古钱币占比 40%
- 收藏人群 1200 万+，每年增长 10%
- 评级币交易占比从 18% 飙升到 **73%**（大多数人只买有鉴定证书的币）
- 头部鉴定商爱藏评级，一年鉴定 912 万枚，收入 20 亿+
- **PCGS 今年刚进中国市场**，标志着标准化时代才开始

一句话：千亿市场，数字化鉴定刚刚起步，窗口期正好。

### 用户痛点

| 人群 | 痛点 | 我们的解决方案 |
|------|------|------|
| 新人藏家（30岁以下占 19.2%） | 不认识是什么币，怕买到假货 | 拍照识别 + 真伪鉴别 |
| 中小拍卖行/币商 | PCGS 评级费 50-200元/枚，排队 2-4 周 | AI 秒级初筛，降本增效 |
| 资深藏家 | 版别细节需要放大镜对比 | 细粒度版式识别（精发/粗发/O版） |
| 知识问答 | 想了解历史背景、市场行情 | GraphRAG 图谱问答 |

## 二、比赛维度：怎么拿国家级金奖

### 评审标准映射

| 评审维度 | 分值 | 我们要怎么拿分 |
|------|------|------|
| **个人成长** | 30分 | 调研过程有录音/问卷/实地拜访数据 → 证明真做了调研，数据组负责 |
| **项目创新** | 30分 | 多任务联合学习 + 知识图谱增强 → 两个创新点都有论文产出，模型组负责 |
| **产业价值** | 25分 | 600亿市场数据 + 与一家本地币商议合作试用 → 证明不是自嗨，系统组负责 |
| **团队协作** | 15分 | 8人分工清晰，GitHub 提交记录、每周站会纪要 → 全部可追溯 |

### 国家级金奖的底线

| 硬指标 | 我们要做到 |
|------|------|
| 专利/软著 | **至少 1 软著**（鉴泉识珍智能鉴定平台），争取 1 专利 |
| 真实数据 | 数据集 10,000+ 枚标注钱币，**公开到 HuggingFace/Zenodo** |
| 论文 | **至少 1 篇**（数据集论文最容易发，模型论文争取） |
| 实地验证 | 联系 1-2 家币商或拍卖行试用，拿到使用反馈/推荐信 |
| 演示效果 | 公网可访问的系统，录 3 分钟路演视频 |

### 和别的项目拉开差距的地方

| 大多数 AI 项目 | 我们 |
|------|------|
| 用现成数据集训个模型 | ✅ 我们也这么做，但有自己爬的 PCGS 数据 |
| 做个网页展示一下就完了 | ✅ 我们做**全栈产品**（注册/鉴定/问答/知识图谱） |
| 只有模型没有知识 | ✅ 我们有知识图谱，能回答历史背景 |
| 只标注了分类 | ✅ 我们有**多任务标注**（版式+品相+分数） |
| 没有开源 | ✅ 我们计划**公开数据集**，这是加分项 |

## 三、商业化维度：如果这不是比赛而是创业

### 产品定位

**"AI 钱币鉴定的第一道关"** —— 不是替代 PCGS 的专业鉴定，而是做规模化初筛。

类比：就像体检报告不是最后诊断，但帮你筛出 80% 的问题。PCGS 是人眼+显微镜的"主任医师"，我们是 AI 的"体检仪器"。

### 商业模式

```
C端 (收藏爱好者):
  - 免费：基础拍照识别（引流）
  - 会员 19元/月：无限次识别 + 品相估值 + 真伪初筛
  - 单次鉴定报告 5 元/份

B端 (币商/拍卖行):
  - API 接口 0.1元/次调用
  - 批量鉴定套餐 999元/月（10000次）

数据增值:
  - 钱币行情数据库、版别分布热力图
  - 鉴定报告白标服务（币商自有品牌）
```

### 竞争格局

| 竞品 | 优点 | 弱点 |
|------|------|------|
| PCGS/NGC | 最权威，全球认可 | 慢（2-4周）、贵（50-200元/枚）、人工为主 |
| 爱藏评级 | 国内最大，912万枚/年 | 人工为主，AI 尚未规模应用 |
| AI 类产品 | 少，主要在学术界 | 没有产品化、没有多任务、没有知识图谱 |

### 差异化

**我们是唯一一个做到"版式识别 + 真伪初筛 + 品相评级 + 知识图谱问答"全链路 AI 覆盖的产品。**
