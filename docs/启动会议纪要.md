# 鉴泉识珍 — 项目启动会议

> 2026-07-16 | 项目负责人：阿轩

---

## 一、项目是什么

一个 AI 古钱币智能鉴定系统。用户上传正反面照片，系统完成：

- **版式识别**：这是什么币（92 种机制银币）
- **品相评级**：保存状态如何（XF/VF/AU/MS）
- **分数评级**：具体多少分（01-66）
- **智能问答**：历史背景、市场行情
- **以图搜图**：在数据库中找和你的币最像的

前端 Vue 3 + 后端 Flask + 模型 YOLO/ONNX/VGG19 + 知识图谱 GraphRAG + 华为昇腾 NPU。

## 二、项目现状

| 模块 | 状态 | 说明 |
|------|------|------|
| 智能鉴定 | ⚠️ 能用 | 31/92 类，模型是学长的 ONNX |
| 品相/分数 | ❌ | 训练数据不够 |
| 智能问答 | ⚠️ | GraphRAG 没装，靠 API 硬撑 |
| 知识图谱 | ⚠️ | Neo4j 没装，前端降级 |
| 估值报告 | ⚠️ | 拼文字，无模型 |
| 真伪鉴别 | ❌ | 完全没有 |
| Docker | ⚠️ | 配置写了，没验证 |
| 数据集 | ✅ | 7,559 枚原始图，6,077 对已裁好已标注 |
| 测试 | ⚠️ | 有 CI，覆盖率不到 1% |

**一句话：骨架搭好了，数据和模型需要补。**

## 五、分工

### 系统组（3 人）

**负责**：产品能跑能看能演示。后端 API、前端页面、Docker 部署、GraphRAG/Neo4j。

**第一周任务**：

| 序号 | 内容 |
|------|------|
| 1 | Docker Compose 跑通，一键启动后端+前端 |
| 2 | GraphRAG 安装配置，Local Search 可用 |
| 3 | Neo4j 启动 + 数据导入 |
| 4 | 熟悉后端 API 所有接口 |

**文档**：[系统组任务书.md](系统组任务书.md)

---

### 模型组（2 人）

**负责**：训模型、评效果、写论文。版式识别、品相评级、多任务学习、知识增强。

**第一周任务**：

| 序号 | 内容 |
|------|------|
| 1 | 用 `data/processed/splits/train.csv` 训版式识别 baseline (VGG19) |
| 2 | Top-1 / Top-3 评测，混淆矩阵 |
| 3 | 对比学长的 ONNX 模型精度 |
| 4 | 确认 ONNX 中间层位置，准备以图搜图方案 |

**文档**：[模型组任务书.md](模型组任务书.md)

### 数据组（1 人 + 论文）

**第一周任务**：

| 2 | 修正 labels.csv 中币名→92 类映射错误（前 200 行） |
| 3 | 统计每类样本数，列出不足 100 对的类别 |
